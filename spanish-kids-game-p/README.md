# Spanish Kids Game (Elementary)

This is a small single-page web game to help elementary children (English speakers) learn basic Spanish.

Features
- Image matching, sentence building, multiple categories
- Hints and explanations for incorrect answers
- Three difficulty levels: Level 1 (basic nouns), Level 2 (phrases), Level 3 (simple sentences + grammar multiple choice)
- Per level: 2 sets of each question type — multiple choice, match pairs, true/false, reorder words, and wheel challenges
- Timed rounds with scoring multiplier based on remaining time
- Rewards (stars/badges) and a local leaderboard stored in `localStorage`
- Warm color theme and cute Mexican-native animal SVGs

Run
- Open `spanish-kids-game-p/index.html` in a browser.

Tips for English-speaking children
- The UI and instructions are in English; questions and answers should be provided in Spanish.
- Hints and explanations are shown in English to support understanding.

Notes
- This is a static, client-side app. You can host it anywhere static files are supported.
